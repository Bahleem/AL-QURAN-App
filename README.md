# AL QURAN — App V1

A mobile-first, installable web app/PWA branded with the supplied AL QURAN logo.

## Included in V1
- AL QURAN dark-green + gold branding
- Home dashboard
- All 114 Surahs list
- Search Surah
- Quran Arabic text + Urdu + English translations (loaded online from AlQuran.cloud)
- Save Ayahs to Favorites (local device storage)
- Share Ayah
- 99 Names of Allah
- Daily Ayat section
- YouTube channel button
- Mobile bottom navigation
- PWA manifest for "Add to Home screen"

## How to use on Android
1. Put this folder on a web host (or run it through a local/static server).
2. Open `index.html` in Chrome.
3. Use Chrome menu → "Add to Home screen" / "Install app" when offered.

## Important
Quran text/translation is loaded from an online API in this prototype. Before publishing to Google Play, the final production version should use a vetted Quran data source, proper attribution/licensing, verified translations, a dedicated recitation audio source, privacy policy, and Play Store assets.
